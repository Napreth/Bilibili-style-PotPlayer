# 字幕与弹幕渲染

文本统一使用 libass 0.17.5。现有两阶段分类保留，分类与可渲染能力分别判断：标准 ASS／SSA 的高级组可播放，B 站 Mode 7／8／9 和专用高级协议不可播放。

## 数据与时钟

- ASS／SSA 保存原始脚本头、样式、画布、事件字段、Layer 和原始顺序，保留事件前后的内嵌字体段。内封 ASS 经 FFmpeg 保留这些信息，并提取 TTF／OTF／TTC 字体附件。选中的同源分类组重新合并，以保持跨组 Layer 与同层顺序。
- 标准 ASS 每次在 PotPlayer 当前媒体时间调用 `ass_render_frame`。暂停使用同一时间，跳转直接渲染目标时间，变速沿用播放器时钟。运动、变换、透明度、裁剪、卡拉 OK 和绘图由 libass 解释。
- SRT 等普通文本生成 ASS 字幕；主副字幕按现有底部布局叠放。XML／JSON 普通弹幕继续使用现有排布与碰撞逻辑生成当前位置，实际字形由 libass 绘制。GDI 只做排布尺寸估计，不再绘制播放中的字幕／弹幕字形。
- 普通文字中的反斜杠和花括号转成全角字面字符，避免被当作 ASS 控制标签；只有标准 ASS 来源保留覆盖标签。

## 样式与开关

普通文本及生成弹幕使用界面中的字体、大小、颜色、透明度、描边和背景设置。原生 ASS 保持作者的字体、坐标、时间及特效，不将通用字号／速度／区域设置强行套到源脚本上。普通 ASS 弹幕遵守 D 总开关、来源开关以及滚动／固定／彩色过滤；标准高级 ASS 遵守来源开关和“高级”过滤开关。C 控制主副字幕。

图像字幕 PGS／VobSub 继续使用 PotPlayer。使用自己的文本层时隐藏原生文本字幕，结束后恢复偏好，避免重复显示。

## 合成与生命周期

`AssScene` 管理选中源和每帧生成的脚本，`LibassRenderer` 管理轨道和字体，`BilibiliAss.dll` 仅封装公共 libass API。ASS 位图按顺序合成为预乘 BGRA，再交给现有透明、穿透输入的窗口。渲染画布按视频显示比例嵌入视口，避开黑边；播放器菜单和控制栏保持在其上方。

每个播放器独立持有上下文。修改选择时释放旧轨道；更换媒体时重建字体库，防止附件字体跨媒体污染；关闭播放器时释放轨道、渲染器和字体库。字体附件限制为每个 16 MiB、合计 32 MiB，脚本限制为 32 MiB。没有额外进程或托盘。

## 依赖构建

`build/libass.ps1` 从校验过的源码构建 libass，使用 FreeType 2.15.0、HarfBuzz 15.0.0 和 FriBidi 1.0.17，固定 Meson／Ninja 版本与选项。字体依赖静态链接于共享 libass，采用 DirectWrite 字体提供器；禁用可选 iconv 自动探测，输入统一 UTF-8。

安装包包含原始源码、构建脚本和选项。许可说明位于 [LICENSES](../LICENSES/README.md)。
