# 操作配置

本版由 PotPlayer 原生鼠标设置和`BilibiliInput.exe` 辅助程序共同实现。原生默认快捷键保持启用，辅助程序放行 F1–F12（F5 除外），处理下表中的操作并屏蔽其他播放器快捷键。多媒体键关闭；输入过滤只作用于获得焦点的播放主窗口。菜单、选项窗口、文件对话框和其他程序仍可正常操作。

| 操作 | 功能 |
| --- | --- |
| → 短按 | 松开时前进 5 秒 |
| → 按住至少 300 ms | 按住期间 2 倍速；松开、切换窗口或退出辅助程序时恢复原速度 |
| ← 短按 | 后退 5 秒 |
| ← 长按 | 初次后退 5 秒，300 ms 后每 100 ms 再后退 5 秒，松开停止 |
| ↑ / ↓ | 音量增加 / 减少 10 个百分点，限于 0–100% |
| Space | 暂停 / 播放 |
| , 或 [ | 上一项 |
| . 或 ] | 下一项 |
| Esc | 退出全屏；窗口模式无动作 |
| F | 进入 / 退出全屏 |
| F1–F12（F5 除外） | 保持 PotPlayer 原生功能，含原生组合键 |
| F5 | 保留给自定义设置页面，当前无动作 |
| M | 静音 / 取消静音 |
| X | 打开 / 收起播放列表 |
| Shift+1 / Shift+2 | 固定 1 倍速 / 2 倍速 |
| D | 普通弹幕总开关，保留各文件的开关状态 |
| C | 字幕总开关，保留主／副字幕选择 |
| S | 切换小窗／正常模式 |
| Enter（含数字键盘 Enter） | 无动作，覆盖默认全屏行为 |
| 视频区域左键单击 | 暂停 / 播放 |
| 视频区域左键双击 | 进入 / 退出全屏 |
| 鼠标滚轮 | 每格增加 / 减少 10 个百分点 |
| 悬停右下角音量按钮 | 显示音量条，移开后收起 |
| 单击音量按钮 | 静音 / 取消静音，保留原音量；零音量时恢复非零音量 |
| 点击或拖动浮动音量条 | 设置 0–100% 音量；0 静音，调高则取消静音 |
| 悬停倍速按钮 | 从上到下显示 10×、5×、3×、2×、1×、0.5×、0.25× |
| 点击倍速菜单项 | 切换到对应倍率并收起菜单 |
| 单击倍速按钮 | 无动作 |
| 悬停声音左边的「字幕和弹幕」 | 字幕选择、主／副双字幕、文件分类与弹幕开关；两侧螺母打开各自设置 |
| 360° 视频中键拖动 / 单击 | 转动视角 / 回到正前方 |
| 普通视频中键、右键、侧键、横向滚轮 | 无动作 |

除上表中的 F 数字键与 Shift+1/2 外，未列出的播放器快捷键及带 Ctrl/Alt/Shift 的组合均无播放器动作。系统窗口切换、关闭窗口等 Windows 操作仍由系统处理。皮肤按钮及进度条可照常点击，左上角 PotPlayer 菜单保留原生选项入口。F5 暂时屏蔽，后续接入自己的设置页面。

音量浮层由辅助程序显示，只显示当前音量，去掉固定的 100% / 0% 端点文字，向上拖动增加音量、向下拖动降低音量。适配本皮肤的右下角按钮位置及 Windows DPI，在窗口和全屏中均可使用。显示或调节时保留播放器焦点，切换到其他程序会收起。

倍速按钮位于「字幕和弹幕」左边。1× 时文字为「倍速」，其他速度为「N×」；从菜单、Shift+1/2 或其他原生入口调整速度后，按钮会跟随实际速度更新。悬停菜单高亮并加粗当前倍率，移开后收起；它与音量条互斥显示。原生速度接口支持 0.2–12×，因此不提供 0.1×。

音频参数在视频参数左边，二者均位于倍速左边。音频仅在无损、至少 24-bit 且至少 96 kHz 时显示 Hi-Res；列表不显示 Hi-Res，改为详细采样率、位深和码率。空间音频与 HDR 仅在源文件包含相关信息时显示，杜比名称跟随 PotPlayer 界面语言。轨道标签使用不同字体，原生菜单确认的选中项加粗；单轨参数变灰且无悬浮列表。

音视频控制栏不显示编码格式，轨道悬浮详情保留编码、位深和码率等规格。视频控制栏示例为 `HDR10 4K@60fps`。常见标准尺寸显示 1080P、4K 等简称；裁切和其他尺寸保留像素，竖屏标准尺寸也可识别。隔行视频的 P 简称改为 I，悬浮列表保留完整像素尺寸。音频详细参数使用 `48kHz/24bit`，支持 `44.1kHz/16bit` 等小数采样率；缺失位深时只显示采样率，缺失采样率时只显示位深。

声道名称随界面语言显示：单声道 `单声道1.0`，双声道 `立体声2.0 / 立体声2.1`，普通多声道 `环绕声5.1 / 环绕声7.1`，包含高度声道的布局 `沉浸式9.1.6`。该布局名称不用于判断杜比全景声或 DTS:X；品牌格式标记继续从源文件的明确格式信息读取。Hi-Res 保留在控制栏，列表仍显示详细规格。

杜比双 D 使用[官网 SVG](https://www.dolby.com/globalassets/logo/dolby_logo_white.svg) 中的原始实心路径，资源及来源说明位于 `plugin/InputBridge/assets/`。SVG 嵌入辅助程序并按原比例绘制；标志高度和纵向位置按相邻文字实际绘出的像素计算，控制栏及选中/未选中的轨道详情均随字号、DPI 和文字颜色变化。100%、150%、200% 的预览已核对同高、同中线。

每个 PotPlayer 窗口都有独立的半透明控制层，嵌入播放器并参与窗口动画。正常模式下，鼠标在播放区域内时显示进度条和完整底栏，移出后隐藏；鼠标进入侧栏不会显示底栏。小窗模式下，鼠标在窗口内时显示精简顶栏、底栏及中央播放控件，移出后只保留视频。悬浮菜单与按键操作只对获得焦点的播放器启用。

全屏模式中鼠标静止 3 秒后收起控制栏，移动后重新显示；操作悬浮菜单或拖动进度条期间保持显示。播放列表在窗口和全屏模式下都占用窗口内部宽度，开关时不改变外窗尺寸、不移动鼠标；右边缘悬停自动展开已关闭。侧栏展开意图与尺寸不足导致的自动收起分开保存，连续缩放不会把自动变化记成用户操作。正常模式的小窗按钮由皮肤与其他标题栏按钮一起绘制。

辅助程序不更改默认轨道标记、语言优先级或文件打开时的选轨结果，也不在文件打开后自动弹出原生轨道菜单。多轨选中状态仅在悬停时从原生菜单读取，点击列表项才发送切轨命令。在原生状态尚未读取时，参数暂用文件首条轨道显示，不强制切换播放器；不显示「音频·2 / 视频·2」等数量占位。

字幕面板由 `SubtitleUi.cs` 直接显示，悬停时不再调用或探测原生字幕弹出菜单。同目录字幕、手动加载文件与容器文本轨道汇总到列表；文件名保留扩展名，容器轨道显示标题或语言，不加“内嵌”标识。单字幕模式显示单选圆点，再点选中项即可关闭；开启多语言后显示主／副，最多两条，空位优先，第三条替换副字幕，关闭主字幕会把副字幕提升为主字幕。列表为单行名称，规格与错误保留在悬停提示中；四种分类的轨道区域等高，每页均容纳三项。圆点表示分页，当前页白色、其他页灰色；超过五页时最多显示五个页标，当前页显示数字，在还有前／后页时显示箭头（如“· · · 4 · ›”“‹ · · · 5 · ›”）。支持滚轮整页切换与点击页标／箭头，翻页不会同时调整音量。“分类存疑”标题为白色；拖动时轨道控件按抓取偏移跟随鼠标，来源位置保持空位，其他轨道在松开前不补位。除了来源分类，其余三类列表改为虚线圆角投放区，居中提示“拖动到此处”，只在投放区内松开才改变分类。

`TimedText.cs` 按内容识别 SRT、ASS/SSA、WebVTT、LRC、TTML、B 站 XML，以及 `{"danmaku":[{"time":1,"text":"…","mode":1,"color":16777215,"size":25}]}` 结构的 JSON。单纯的时间／文本 JSON、缺少用途声明的动画／绘图 ASS 放入“分类存疑”，可拖到字幕、普通弹幕或高级弹幕区，也可拖回；扩展名本身不作为字幕／弹幕的判断依据。B 站 XML 和 JSON 中普通与高级条目混存时拆为两个来源。高级、代码及 BAS 弹幕只识别、列出和计数，开关禁用，脚本不执行；复杂 ASS 也不会自动当作普通弹幕播放。

`CaptionCatalog.cs` 用 MediaInfo 列出容器文本轨道，选中后通过FFmpeg 的 `0:s:n` 映射只读提取为 SRT，再由 `TimedOverlay.cs` 按播放器进度显示。支持暂停、定位、倍速及两条文本字幕同时显示；ASS 使用统一文本样式，不复现原有动画／绘图。PGS、VobSub 等图像字幕列出并注明限制，继续由 PotPlayer 原生渲染，本面板暂不切换。辅助程序显示文本字幕期间隐藏原生字幕，正常退出辅助程序时恢复先前的显示状态；播放器已经关闭时也恢复其保存的 `CaptionVisible` 偏好，避免影响下次播放。

普通弹幕支持滚动、反向滚动、顶部／底部固定，以及基础颜色、字号；每个来源独立开关，D 控制总开关。同名配套 XML 自动开启，目录中的其他文件仅列出；从文件手动加载的普通弹幕直接开启。弹幕布局由媒体时间重建，暂停时静止，定位后对应当前时间。设置参考 B 站：滚动／固定／彩色过滤、随屏幕缩放、防挡字幕、显示区域、不透明度、字号、速度；高级过滤暂不可用。

两侧六边形内圈螺母分别进入字幕和弹幕设置。字号移入弹幕设置；两侧均使用分组的字体、字号、粗体／斜体、主题颜色、背景填充及描边控件，字体列表在面板内部显示字体预览，效果预览与实际渲染共用绘制函数。字幕另可调整不透明度和距底部。设置及手动分类存于 `%LOCALAPPDATA%\BilibiliPotPlayer\caption-options.json`，分类键为文件路径散列。翻译和语音生成入口为灰色“未接入”；在线字幕搜索由明确点击后打开原生搜索窗口，不自动发起网络请求。F5 继续保留给后续自定义设置。

原生菜单输出方式使用「系统菜单」以读取音视频轨道及 360° 选项状态；该选项纳入安装备份和恢复。运行中更新时从「皮肤 → 菜单输出方式」应用，关闭播放器后安装则自动配置。字幕显示开关通过初始化私有菜单资源副本读取，不显示原生弹出菜单。控制栏的新悬浮面板采用本项目的深色样式。

360° 手势由 `CameraControl.cs` 接入，原生鼠标左键单双击设为空操作，再由辅助程序提供左键单击暂停/播放、双击全屏。双击不会同时改变播放状态。关闭原生四视角预览，不改变投影类型、视角灵敏度和原生相机的俯仰限制；单击中键选择原生正前方预设。

中键视角操作借用原生左键事件，`CameraPlaybackGuard` 在这些内部事件前记录播放状态，并在原生单／双击判定的延迟窗口内恢复误触的状态；拖动松开时重新记录当前状态。实际左键与空格会解除该保护，停止或切换媒体会清除保护。中键开始前如果有尚未判定的真实左键单击，先结算一次，避免稍后在视角手势中重复触发。

自动模式结合 MP4 的 Google V1 / V2 全景元数据，或明确带 360° / 360 VR 标记的 2:1 文件启用手势；普通 2:1 电影不会仅因画幅启用。手动强制 360° 模式支持其他投影。元数据判定参考 [Google V1](https://github.com/google/spatial-media/blob/master/docs/spherical-video-rfc.md) 和 [Google V2](https://github.com/google/spatial-media/blob/master/docs/spherical-video-v2-rfc.md)，有读取数量和 XML 长度限制，不解码、不修改媒体、不联网。

运行中更新应先在原生选项中将左键单双击设置为「什么都不做」，确认由辅助程序接管后再使用 `-UseConfiguredPlayer`。该模式不覆盖运行中的原生配置；部分新设置直到播放器退出才写入注册表，所以不以旧的鼠标注册表值否定已在界面应用的设置。

## 安装

适用于 Windows 10/11、64 位 PotPlayer，要求支持 2023-08-30 之后的 `InternalSimpleCmd` 速度接口及 .NET Framework。容器文本软字幕另外需要FFmpeg，依次查找辅助程序目录、当前用户 WinGet 链接目录、PATH。找到有效解码器立即返回，跳过带非法字符的 PATH 项，并处理带引号的目录；格式错误的 PATH 项不会阻断已安装 FFmpeg 的查找。未找到时仍可使用外挂文本字幕和普通弹幕，对容器轨道显示具体错误，轨道仍可点选重试，不会永久变灰。拖到普通弹幕分类时加载容器文本；失败后开关可重试，已加载内容重复开关不重新解码。先关闭 PotPlayer，再在项目目录执行：

```powershell
pwsh -NoProfile -File settings/install-input.ps1
```

脚本编译程序、备份将修改的交互配置、清空原生自定义主窗口快捷键、应用 `input-profile.json`，并安装 PotPlayer 启动扩展。辅助程序和配置位于播放器安装目录的 `Extension/BilibiliInput/`，原始备份仍位于 `settings/.local/`，不进入 Git。安装目录需要写权限；它不记录键盘内容，读取当前媒体路径以获取参数，不将路径写入日志，也不联网。

辅助程序由 PotPlayer 的 `OnInitialize` 扩展入口拉起，正常启动播放器或双击视频文件都会启用。最后一个 PotPlayer 实例退出后，辅助程序在一秒左右自动退出。没有登录自启、计划任务或等待播放器启动的常驻监视程序；安装时会清除早期版本添加的 `BilibiliPotPlayerInput` 登录自启项。

启动扩展为 `Extension/Media/PlayParse/MediaPlayParse - BilibiliInput.as`，只负责启动辅助程序，媒体匹配函数均返回 false。多个播放器实例共用一个辅助程序。托盘菜单可提前退出辅助程序；再次启动播放器时重新启用。安装脚本支持 `-PlayerPath '完整的 PotPlayerMini64.exe 路径'`，运行中播放器的路径会自动检测。

`-UseConfiguredPlayer` 用于原生设置已经通过选项界面应用的当前播放器，会核对启用默认快捷键、关闭多媒体键、右键空操作、关闭关键帧定位及主窗口自定义快捷键为空；安装扩展并为当前实例启动辅助程序，不重启播放、不从注册表强行覆盖运行中播放器的配置。

修改 `input-profile.json` 中的长按阈值、回退间隔或步长后，重新运行安装脚本即可。按键过滤位于 `plugin/InputBridge/InputLogic.cs`，操作映射位于 `BilibiliInput.cs`，浮动音量条位于 `VolumePopup.cs`，倍速按钮和菜单位于 `SpeedUi.cs`；字幕与弹幕分别见 `SubtitleUi.cs`、`CaptionCatalog.cs`、`TimedText.cs`、`TimedOverlay.cs`。

## 恢复

关闭 PotPlayer 后执行：

```powershell
pwsh -NoProfile -File settings/restore-input.ps1
```

恢复首次安装前的交互设置和主窗口自定义快捷键，并移除本项目启动扩展。同时恢复四个 360° 预览的原始设置；皮肤、解码器、字幕和播放列表不受影响。不要删除 `settings/.local/original-input.json`，重复安装会沿用这份原始备份。

## 验证与接口来源

```powershell
pwsh -NoProfile -File plugin/InputBridge/build.ps1 -Test
plugin/InputBridge/bin/InputBridgeTests.exe --status
```

第一条执行输入、媒体与布局逻辑检查，覆盖按键和长按、控件布局及 DPI、Hi-Res/HDR/声道和参数格式、原生轨道菜单匹配、MP4 Dolby Vision RPU、全景元数据，以及字幕内容识别、混合弹幕分组、外部实体拒绝、时间解析、主／副选择、弹幕布局、三条轨道分页、五页滑动窗口与投放区边界、容器读取失败后重试及加载期间改分类／关闭开关、中键事件造成的延迟播放切换保护、真实左键与空格的保护解除。第二条只读取播放器状态。`--ui-status` 只读输出父窗口、层级、DPI、坐标和可见状态；`--caption-inspect "媒体文件"` 读取容器字幕列表并实际提取各文本轨道，用于验证流序号映射；`--caption-preview "输出目录"` 将常规和拖动状态绘制为 PNG，不发送鼠标或键盘事件。实体键盘长按可用暂停或播放的视频手动核对。

2026-10-14 列表与中键更新实测：正常菜单只有单行名称与页点，滚轮按每页三条轨道翻页，当前页点变白且音量不变；文件可拖到普通弹幕区并拖回存疑区，拖动状态的空位、跟随鼠标的控件和三个虚线投放区已渲染核对。实际左键单击由播放变为暂停，双击进入全屏且仍暂停，Esc 恢复窗口。360° 视频播放时中键回正后仍为 Running，暂停时回正后仍为 Paused 且进度不变。中键拖动逻辑沿用此前用户确认正常的原生旋转，新加的状态保护通过检查，实体中键拖动本轮未自动化模拟。

杜比视界优先于其 HLG / HDR10 兼容基础层。部分重封装 HEVC MP4 缺少 `dvcC` / `dvvC` 容器配置，MediaInfo 只能报告 HLG；`DolbyVisionProbe.cs` 对这种文件按轨道 ID 检查前 32 个样本的 RPU NAL 头及 CRC，确认元数据后显示杜比视界。普通 HLG 没有该元数据时仍显示 HLG。此补充仅支持普通 MP4 样本表，其他封装继续使用 MediaInfo；不解码图像、不调用外部程序、不修改媒体文件。RPU 格式和校验参考 [FFmpeg 帧内元数据解析](https://github.com/FFmpeg/FFmpeg/blob/master/libavcodec/dovi_rpudec.c)，HLG 兼容基础层见 [Dolby 官方说明](https://professionalsupport.dolby.com/s/article/Dolby-Vision-for-video-sharing-services-FAQs)。
